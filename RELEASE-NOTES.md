Blue One Riyal Coupons 1.1.0

Public GPL release of the SAR 1 coupon plugin, with WordPress.org readme metadata, proper scoped asset loading, escaped translatable messages and native WooCommerce coupon management.

Install the attached blue-one-riyal-coupons.zip through WordPress's Upload Plugin screen. Requires WooCommerce and SAR transactions. Tax uses the store price-entry basis; shipping and fees remain separate.

Validation: official Plugin Check reported no findings, WordPress Coding Standards passed, and isolated plus real WooCommerce integration tests passed on WordPress 7.1.3 / WooCommerce 11.2.1.

WordPress.org directory approval is separate from this public GitHub release. Browser checkout and third-party payment/provider integrations have not been tested.
